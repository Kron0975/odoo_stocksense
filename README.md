# StockSense — Person 1

## Hour 1 milestone

This project is based on the supplied StockSense requirements and Excalidraw mockups.

### Implemented
- ERP-style top navigation
- Operations dropdown with Receipts, Delivery and Adjustment
- Stock/Product list screen
- Product, Per Unit Cost, On Hand, Free to Use
- Search by product/SKU
- Update stock from the Stock screen
- REST API foundation using Node.js + Express
- GET product API
- GET single product API
- PUT stock update API
- Validation: Free to Use cannot exceed On Hand
- Delivery detail screen shell matching the supplied mockup

### Run

1. Install Node.js.
2. Open this folder in VS Code terminal.
3. Run:

   npm install
   npm start

4. Open:

   http://localhost:3000
